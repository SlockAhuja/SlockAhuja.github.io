## Deployment

This website is configured to be automatically deployed to GitHub Pages via GitHub Actions.

1. Create a `.github/workflows/deploy.yml` in your repository.
2. Ensure the repository settings have GitHub Pages enabled to deploy from GitHub Actions.
3. Upon pushing to the `main` branch, the workflow will build the Vite app and publish it automatically.
